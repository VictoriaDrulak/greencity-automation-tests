# GreenCity Events Page Automated Tests

Автоматизовані тести сторінки подій GreenCity за допомогою Python + Selenium + unittest.

Сторінка для тестування: https://www.greencity.cx.ua/#/greenCity/events

## Структура проєкту
- `tests/` — автоматизовані тести Python
- `test-cases/` — опис тест-кейсів у форматі .md
- `requirements.txt` — необхідні бібліотеки

## Запуск тестів
python -m unittest discover tests
